### redirectUri

```ts
redirectUri: string;
```

Redirect URI registered with the provider. Must serve a page that calls
[handleOAuthCallback](/api/client/functions/handleOAuthCallback) (popup and deferred modes) or is your app route
that reads the returned `?code=` (redirect mode).
