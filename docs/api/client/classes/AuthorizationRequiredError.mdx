Thrown in deferred mode when the user must authorize. Show a control whose
click handler calls [AuthorizationRequiredError.openPopup](#openpopup), await
[BrowserOAuth.completeAuthorization](/api/client/classes/BrowserOAuth#completeauthorization), then reconnect or retry the
request.

authorization. Returns `false` when the popup was blocked.
